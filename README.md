# Nest in Korea — 모바일 웹앱 (PWA)

## 바로 실행
`index.html`을 더블클릭하면 기본 기능을 테스트할 수 있습니다. 스마트폰에 설치하거나 오프라인 기능을 사용하려면 HTTPS 호스팅이 필요합니다.

## 로컬 개발
Python이 설치되어 있다면 이 폴더에서 `python3 -m http.server 8000`을 실행하고 브라우저에서 `http://localhost:8000`으로 접속하세요.

## 배포
이 폴더 전체를 GitHub Pages, Netlify 등 정적 웹 호스팅에 업로드하세요. HTTPS 주소로 접속하면 브라우저의 '홈 화면에 추가' 기능으로 설치할 수 있습니다.

## 구현 범위
8개 화면, 4개 언어(주요 인터페이스), 개인정보 로컬 저장, 계약서 안내, 체크리스트 저장, 행정절차 설명, 간단 검색, PWA manifest 및 서비스 워커.

## 유의 사항
서버나 회원가입이 없는 **기기 내 저장 데모**입니다. 여러 기기 간 동기화되지 않으며 브라우저 데이터를 삭제하면 기록이 사라집니다. 실제 행정·법률 절차는 반드시 공식 기관 최신 안내를 확인하세요. 세부 가이드 일부는 한국어로 제공됩니다.
